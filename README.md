# ColorBlocks Mod

A Minecraft 1.21.1 NeoForge mod that adds 98,304 colored blocks in pure RGB565 colors.

## Features
- 32,768 unique colors (32×32×32 RGB565 color space)
- 3 block types per color: Full block, Slab, Vertical Slab
- Total: 98,304 blocks
- Mineable with iron pickaxe
- No light emission
- Code-generated textures at runtime

## Building
```bash
./gradlew build
```

## Requirements
- Minecraft 1.21.1
- NeoForge 21.1.86
- Java 21
